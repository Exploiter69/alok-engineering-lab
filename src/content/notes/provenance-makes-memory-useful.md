Memory without provenance is difficult to trust.

If a system remembers a fact, useful questions include: where did it come from, when was it observed, what evidence supports it, and has it since been superseded?

VGU Signal treats source evidence as part of the information lifecycle. VAJRA treats engineering memory as provenance-bound state.

The common lesson is that history is part of the data, not merely a log around it.
