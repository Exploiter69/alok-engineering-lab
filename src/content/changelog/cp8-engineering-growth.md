CP8 focuses on a simple product question: can the Lab show not only what has been built, but what is being worked on now?

The existing content model already carried project status. CP8 makes that signal visible across project cards and project detail pages.

The phase also adds a durable note and experiment explaining the boundary between documented project status and live operational health.

No database, CMS, analytics, runtime API or paid service was introduced.

The result is a more useful living archive without changing the Astro architecture or the zero-cost operating model.
