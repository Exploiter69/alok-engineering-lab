CP10 upgrades project pages from descriptive case studies into structured technical records.

Each project now exposes its current objective, lifecycle, architecture summary, technology, repository, important decisions, lessons, connected knowledge and linked timeline entries.

The project remains static and repository-backed, so the richer record does not create a second source of truth.
